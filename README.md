# テニス部連絡ノート

中学生テニス部の自主練習を、保護者どうしで連絡し合うためのWebアプリです。

## 構成

| 場所 | 内容 |
|---|---|
| `web/` | 公開するアプリ（Firebase Hosting）。画面は `index.html`、Firebase との接続は `backend.js` |
| `functions/` | サーバー側の処理（ログイン・登録コード・管理者パスワード・プッシュ通知） |
| `firestore.rules` / `storage.rules` | データと写真の読み書きのルール（サーバーで確認される） |
| `tests/` | Firebase エミュレーターでのエンドツーエンドテスト |
| `artifact/` | 以前の claude.ai Artifact 版（https://claude.ai/artifact/AuJ2uYDZpuM5gSdSQFvzCy）。今後は更新しない |

公開の手順は [DEPLOY.md](DEPLOY.md) を見てください。

## セキュリティ

- データはログインしないと一切読めない・書けない。家庭としてログインした人は、自分の家庭のお子さんの分だけ書ける（`firestore.rules`）。
- 家庭のパスワード・登録コード・管理者パスワードはサーバーだけが確認し、ハッシュ（PBKDF2）だけを保存。画面からは読めない。
- 5回まちがえると15分ロック（サーバー側で数える）。
- ログインはタブを開いている間だけ。開き直すたびにパスワードが必要。
- 最初の管理者パスワードは、デプロイ時に決めるセットアップキーを知っている人だけが設定できる。

## 画面

| 画面 | 内容 |
|---|---|
| ホーム | 次回の自主練習と参加ボタン、重要なお知らせ、未対応の項目 |
| 練習予定 | 月のカレンダー、予定の作成・編集・複製・中止、変更履歴、各練習の送迎状況 |
| 予定の詳細 | 概要／出欠／送迎（乗せられる・乗りたい・調整結果）／持ち物／連絡 |
| 費用管理 | テニスコート代金の立替と月1回の精算、支払い履歴、家庭ごとの集計（未払いは管理者と本人だけに表示） |
| 連絡掲示板 | 全体連絡／練習日ごと／重要連絡、既読・確認・返信 |
| 練習記録 | 練習メニュー／活動記録／大会情報、写真 |
| マイページ | 家族（兄弟姉妹の追加）、今月の参加と精算、プッシュ通知のオン・オフ |
| 管理者画面 | ダッシュボード、予定一覧、参加管理（当日来た子の追加）、送迎、費用、メンバー登録、登録コードとパスワードのリセット、設定 |

## お知らせ（プッシュ通知）

練習予定・送迎・連絡の新規登録や変更、管理者が参加を記録したときに、Firebase Cloud Messaging で通知します（自分の家庭の操作は通知しない。管理者が記録した参加は対象の家庭だけ）。保護者は「マイページ」かホームの案内から、端末ごとに通知をオンにします。アプリ内でも右上のベルに新着が表示されます。

## データ（Firestore のコレクション）

`members`（選手と家庭）、`practices`（練習予定・変更履歴・練習記録）、`responses`（参加と送迎の登録）、`rides`（送迎のお願い・決定）、`payments`・`costs`（テニスコート代金などの立替と精算）、`posts`・`comments`・`reads`・`likes`（連絡掲示板）、`settings/app`（端数ルール・緊急連絡先）、`pushTokens`（通知の宛先）、`secrets`（パスワードと登録コードのハッシュ。サーバー専用）。
