# テニス部連絡ノート

中学生テニス部の自主練習を、保護者どうしで連絡し合うためのWebアプリです。

- 公開中のアプリ：https://claude.ai/artifact/AuJ2uYDZpuM5gSdSQFvzCy
- このリポジトリは、アプリのソース（`index.html`）のバックアップと変更履歴のためのものです。

## 動かし方について

`index.html` は claude.ai の Artifact として公開して動かします。共有データ・閲覧者の判定・写真の保存は、Artifact の機能（`window.claude.use("db" | "user" | "assets")`）を使っています。
そのため、ファイルを直接開いたり GitHub Pages などに置いたりすると「共有データに接続できません」と表示され、データの保存はできません。

更新するときは、`index.html` を編集してから、同じ Artifact に公開し直してください（URLと保存済みのデータはそのまま残ります）。

公開時に宣言している機能：

```json
{ "db": {}, "user": {}, "assets": { "upload": "interact" } }
```

## 画面

| 画面 | 内容 |
|---|---|
| ホーム | 次回の自主練習と参加ボタン、重要なお知らせ、未対応の項目 |
| 練習予定 | 月のカレンダー、予定の作成・編集・複製・中止、変更履歴 |
| 予定の詳細 | 概要／出欠／持ち物／連絡 |
| 送迎調整 | 乗せられる／乗りたい／調整結果 |
| 費用管理 | 今月の精算（参加者で割り勘）、支払い履歴、家庭ごとの集計 |
| 連絡掲示板 | 全体連絡／練習日ごと／重要連絡、既読・確認・返信 |
| 練習記録 | 練習メニュー／活動記録／大会情報、写真 |
| マイページ | お子さんの選択（兄弟姉妹は複数可） |
| 管理者画面 | ダッシュボード、予定一覧、参加管理（当日来た子の追加）、送迎、費用、メンバー、設定 |

## 権限

Artifact の共有メニューで設定します。

- 保護者：Contributor（予定の作成、参加登録、送迎、支払い、掲示板、記録）
- 管理担当：Editor（管理者画面、当日来た子の追加、選手の削除、固定表示）

## データ（共有データベースのコレクション）

| コレクション | 内容 |
|---|---|
| `members` | 選手（名前・保護者名・家族のまとまり） |
| `practices` | 練習予定（日付・時間・コート・コート番号・費用・集合・持ち物・締切・中止・変更履歴・練習記録） |
| `responses` | 参加登録（練習×選手で1件。送迎の可否・人数・経路・乗る場所、管理者が追加したかどうか） |
| `rides` | 送迎の依頼と決定 |
| `payments` | 支払いの記録（支払った人・支払い先・日付・金額） |
| `costs` | ボール代・備品代など |
| `posts` / `comments` / `reads` / `likes` | 連絡掲示板 |
| `settings/app` | 端数ルール、責任者、緊急連絡先、緊急時の手順 |
| `data/users/<id>/profile` | 各保護者が選んだお子さん（本人だけが読める） |

保存されたデータはこのリポジトリには含まれません。
