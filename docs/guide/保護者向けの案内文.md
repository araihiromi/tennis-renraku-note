# 保護者向けの案内文

`docs/guide/` の画像（01〜06）と一緒に使ってください。【 】の中は、送る前に書き換えてください。

## 1. グループに送る文章（全員向け）

> 画像 01〜06 と一緒に送ります。**登録コードはグループには書かないでください。**

```
【テニス部 自主練習の連絡アプリを始めます】

保護者の皆さま
いつもありがとうございます。
自主練習の予定・参加・送迎・テニスコート代金の連絡を、これから「テニス部連絡ノート」というアプリでまとめて行います。

▼アプリのURL（インストール不要。Safari・Chromeで開けます）
https://tennis-renraku-note.web.app

▼はじめかた
1. 各ご家庭に、管理担当から「登録コード（6けた）」を個別にお送りします
2. URLを開き、お子さんの名前を選んで、登録コードを入れます
3. ご家庭のパスワード（6文字以上）を決めてログインします
4. 「マイページ」→「この端末で通知を受け取る」を押すと、新しい予定や連絡がスマートフォンに届きます

詳しい使い方は、添付の画像をご覧ください。

▼お願い
・電話番号・住所・メールアドレスなど、氏名以外の個人情報はアプリに書かないでください
・パスワードと登録コードは、ご家族以外に教えないでください
・アプリを開くたびにパスワードの入力が必要です

わからないことがあれば、【管理担当の名前】までお気軽にご連絡ください。
```

## 2. 各家庭に個別に送る文章（登録コード付き）

> 管理者画面の「ログインとパスワード」で発行したコードを入れて、**その家庭だけ**に送ります。コードは1回だけ使えます。

```
【テニス部連絡ノート 登録コードのお知らせ】

【お子さんの名前】さんの保護者さま

アプリの登録コードをお送りします。
はじめてのログインで1回だけ使います。

登録コード：【123456】

1. https://tennis-renraku-note.web.app を開く
2. 「お子さん」で【お子さんの名前】を選んで「つぎへ」
3. 登録コードと、ご家庭で決めたパスワード（6文字以上）を入れて「パスワードを設定してひらく」

※ このコードはほかの方に見せないでください
※ パスワードを忘れたときは、【管理担当の名前】にご連絡ください（リセットして新しいコードをお送りします）
```

## 3. くわしい説明（配布資料やお知らせ用）

### テニス部連絡ノートとは
自主練習について、保護者どうしで連絡し合うためのアプリです。スマートフォンのブラウザで使えて、アプリのインストールは不要です。

### できること
| 画面 | できること |
|---|---|
| ホーム | 次回の練習の確認と「参加する」、重要なお知らせ、未対応の項目 |
| 予定 | 月のカレンダー、練習予定の作成。練習ごとに参加者・送迎・持ち物・連絡を確認 |
| 送迎 | 車を出せる方は「乗せられる」、乗せてほしい方は「乗りたい」で登録。決まると通知 |
| 費用 | テニスコート代金を参加した人で割り勘。月に1回、誰にいくら払うかを表示 |
| 連絡 | 全体連絡・練習日ごとの連絡・重要連絡。確認しましたボタンや返信 |
| 記録 | 練習メニュー・気づき・写真・大会情報 |

### ログインについて
- ログインは「お子さんの名前 ＋ ご家庭のパスワード」です。兄弟姉妹は同じパスワードでまとめて使えます。
- アプリを開くたびにパスワードの入力が必要です（スマートフォンを家族以外が触っても見られないようにするため）。
- 5回続けて間違えると、15分間ログインできなくなります。
- パスワードを忘れたときは管理担当に連絡してください。リセットして、新しい登録コードをお送りします。

### テニスコート代金について
- 練習の日は、どなたかがコートで代金を立て替えて払い、アプリで「テニスコート代金を払った」を押して記録します。
- 代金は、その練習に「参加」した人で割り勘になります（欠席した日はかかりません）。
- 月に1回、「誰にいくら払うか」がアプリに表示されます。お金を渡したら「未払い」を押して記録してください。
- 支払う金額は、そのご家庭と管理担当だけに表示されます。

### 通知について
- 「マイページ」→「この端末で通知を受け取る」でオンにします。スマートフォンごとの設定です。
- iPhone は、Safari の共有ボタン →「ホーム画面に追加」で作ったアイコンから開いて、通知をオンにしてください（iOS 16.4 以降）。
- ご自分の家庭が登録・変更したものは、ご自分には通知されません。

### 個人情報について
- アプリに登録するのは、児童と保護者の氏名だけです。
- 電話番号・住所・メールアドレスなどは書かないでください（書こうとすると保存できません）。
- 写真を載せるときは、写っているお子さんと保護者の了承を得てください。
